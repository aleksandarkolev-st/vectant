# Therapeutic Tomography Release Evidence Status

`docs/THERAPEUTIC_TOMOGRAPHY_RELEASE_EVIDENCE.json` is currently a stale
repo-local v1 artifact. It uses `example.test` endpoints, file-backed runtime
state, and local HMAC signing, so it is intentionally rejected by the production
v2 validator and must not be used as deployed production proof.

The production replacement must be generated by:

```powershell
npm --prefix mcp/synthi-mcp run proof:dojo:therapeutic-tomography:release-evidence
```

That command fails before writing unless it observes:

- production HTTPS runtime authorization context with matching tenant/RBAC
- production HTTPS probe execution for the incident-response probes
- external control-plane durable-state append and readback reconstruction
- managed-key or external-command Ed25519 proof signing and verification
- protected dispatch denied before grant, approved during active grant, and
  denied after revocation
- narrative-only proof denied for broad access, raw logs, model weights, admin
  privileges, full DB access, mutation, and production writes

After the v2 JSON is produced, generate the visual proof report from the
validated artifact:

```powershell
node mcp/synthi-mcp/scripts/dojo-therapeutic-tomography-visual-report.mjs `
  --evidence docs/THERAPEUTIC_TOMOGRAPHY_RELEASE_EVIDENCE.json
```
